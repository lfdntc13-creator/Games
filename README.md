# Clara: controle financeiro pessoal

Aplicativo simples para planejar receitas e despesas futuras. Para testar localmente, abra `index.html` em um navegador.

## Uso

- Os meses começam no próximo mês. Use **Novo lançamento** para registrar uma entrada, como salário, ou uma saída, como uma conta.
- Escolha o mês e o horizonte da projeção para acompanhar o saldo estimado.
- Os dados ficam no armazenamento local do navegador e não são enviados ao projeto. Eles não sincronizam entre dispositivos; exporte um CSV para guardar uma cópia.
- O botão **Enviar feedback** abre um formulário de Issues. É necessário entrar no GitHub. Não inclua informações pessoais, bancárias ou valores reais no feedback.
